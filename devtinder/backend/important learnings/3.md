[1] **THE ANSWER**

**Multer** is a middleware used in **Node.js + Express** to **handle file uploads**.

In very simple words:
👉 Multer helps your server **receive files** (like images, videos, PDFs) sent from a form.

What Multer does:

* Reads files sent from HTML forms (`multipart/form-data`)
* Stores files on **disk** or **memory**
* Gives you file info (name, size, type)
* Lets you control:

  * Where files are saved
  * File size limits
  * Allowed file types (image only, etc.)

Without Multer ❌
Express **cannot** read uploaded files.

With Multer ✅
You can easily upload and save files.

Example use cases:

* Profile photo upload
* Resume upload
* Product image upload

### 📌 **Middleware (Backend Concept)**

**Middleware** is code that runs **between request and response**.

Simple flow:

```
Request → Middleware → Controller → Response
```

Why middleware is powerful:

* Logging
* Authentication
* File uploads (Multer)
* Validation

Think of middleware as a **security + processing gate** before your logic runs.
